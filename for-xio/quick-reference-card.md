# Xio's Quick Reference Card

## Your workflow

```
Browse https://www.whappin.com/
       ↓
See something off?
       ↓
Scroll to footer → Click "Report a problem"
       ↓
Fill in: What happened? What page? Device?
       ↓
Click submit → We get the issue → We fix it
```

## What to check on each business page

| Thing to check | What's wrong if... |
|---------------|-------------------|
| Business name | Doesn't match the sign outside |
| Phone number | Wrong or disconnected |
| WhatsApp link | Goes to wrong person |
| Website link | Broken or wrong site |
| Category | Hotel listed as restaurant, etc. |
| Description | "X is a Y in Z" — auto-generated, needs rewrite |
| Amenities | Nothing listed (empty section) |
| Star rating | Missing — should show "from Google Maps" |
| Map pin | Shows wrong location |
| QR code | Doesn't scan to this business |
| Status | Business closed but still showing contact buttons |

## Severity guide

| Severity | When to use | Example |
|----------|------------|---------|
| **Broken** | Feature doesn't work | Link goes nowhere |
| **Wrong** | Data is incorrect | Wrong phone number |
| **Confusing** | Hard to understand | Unclear what a button does |
| **Polish** | Looks off but works | Alignment, spacing |
| **Idea** | Would be nice to have | "Wish this had photos" |

## What to prioritize

1. **Wrong data first** — bad phone numbers, closed businesses, wrong categories
2. **Missing data second** — no description, no amenities, no Instagram
3. **Polish last** — spacing, wording, layout

## The most helpful issue includes

- Business name
- Page URL (copy from address bar)
- What you expected vs what happened
- Device (Desktop / Phone)
